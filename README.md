## 1. 为什么有这份文档

2025 年,每年有数以万计的内地学生去香港读书。但所有的攻略都散落在:

- 公众号的付费文章里 🔒
- 小红书随手刷到就再也找不到的帖子 📱
- 学长学姐口口相传、一人一份的私藏版本 🤫
- 以及……各种过时了三年的「旧版本」🗑️

**没有一份开源的、可持续维护的、像文档一样规范的版本。**

所以这个项目出生了——把留学准备拆成一个个「接口」,由亲历者 PR 持续维护,版本可追溯,信息可核对。README 即产品,文档即攻略。

## 2. 快速开始 (Quick Start)

```bash
# Step 0: 拿到 offer(本项目不负责这个)
# Step 1: 学生签注 —— GET /api/visa
# Step 2: 订房      —— POST /api/flat
# Step 3: 抵港激活  —— POST /api/onboarding
# Step 4: 开户通信  —— POST /api/bank + GET /api/sim
# Step 5: 毕业留港  —— GET /api/job (IANG 规划)
```

每个接口都是独立文档,按需阅读,无需按顺序。

## 3. API 总览 (Endpoint Reference)

| Endpoint | 方法 | 说明 | 状态 |
|---|---|---|---|
| `/api/visa` | `GET` | 学生签注 + IANG 毕业规划 | ✅ 可用 |
| `/api/flat` | `POST` | 租房(含押金/厘印/免佣盘) | ✅ 可用 |
| `/api/payment` | `GET` | 八达通 / FPS / 支付生态 | ✅ 可用 |
| `/api/bank` | `POST` | 银行开户与跨境汇款 | ✅ 可用 |
| `/api/sim` | `POST` | 电话卡「上台」与网络 | ✅ 可用 |
| `/api/onboarding` | `POST` | 抵港 Day-1 清单 | 🚧 WIP |
| `/api/job` | `GET` | 港漂程序员就业(IANG) | 🚧 WIP |
| `/api/food` | `GET` | 食堂/茶餐厅速览(快乐加成) | 🧪 alpha |
| `/api/heart` | `GET` | 心情接口(人間觀察,状态码即情绪) | 🧪 alpha |

## 4. 设计原则

1. **信息可核对**:每条经验尽量标注「信息来源/验证方式」,拒绝「听朋友说」。
2. **版本可追溯**:政策会变,攻略也会变。改动走 `CHANGELOG.md`,重要政策变化标 `BREAKING CHANGE`。
3. **亲历者维护**:内容来自真实经历 + 学长学姐 PR,不是我一个人在编文档。
4. **粤语友好**:全文保留粤语注释,是给同路人看的暗号,也是这份文档的签名。

## 8. FAQ

**Q: 这不是攻略吗,为什么要写成 API 文档?**
A: 因为作者是程序员,而且觉得「状态码 401 = 材料不齐」比「请准备好以下材料」更好记。

**Q: 信息准确吗?**
A: 每条都尽量标注来源和验证方式。政策类信息请以官方(`gov.hk` / 学校)为准。

**Q: 我想贡献但没去过香港。**
A: 检查我们的文档也是贡献!格式、链接、错别字、逻辑漏洞,全部欢迎 PR。

**Q: 为什么叫 `import-hk`?**
A: `import` 是程序员最熟悉的一个词——引入一个依赖,世界就多了一部分。`import hk`,一行代码,入境香港。顺便说,它大概是全站最容易读懂的 import。
