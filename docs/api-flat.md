# `POST /api/flat` — 租房

> 香港租房,可能是你人生中第一次接触到「押二付一」「一年死约」这些词。
> 放心,读这篇,你比 90% 的新生懂行。

---

## 1. Request Body(请求参数)

```json
{
  "budget": "8000 HKD/月(合租可下调)",
  "district": "九龙/港岛/新界",
  "near_campus": true,
  "accept_subdivided": false,
  "move_in_date": "2026-08-15",
  "roommate_group": "3 人(可选)"
}
```

| 参数 | 说明 |
|---|---|
| `budget` | 单间 6k–12k 常见,校区旁更贵;合租是学生主流方案 |
| `district` | 学校在哪区,优先同区或地铁直达区(通勤时间 = 生活质量) |
| `accept_subdivided` | 劏房(分间单位)便宜但慎选,见 Troubleshooting |

---

## 2. 找房渠道(数据源)

| 渠道 | 类型 | 备注 |
|---|---|---|
| **28Hse** (`28hse.com`) | 平台 | 业主/代理直租盘,量大 |
| **591 揀樓** (`591.com.hk`) | 平台 | 同上,香港版 58 同城 |
| 中原/美联/利嘉阁 | 传统代理 | 可靠但收佣金 |
| 寄托天下租房版 | 论坛 | 学长学姐转租、合租,性价比高 |
| 小红书/微信港漂群 | 社交 | 一手转租信息快,但注意甄别 |
| 学校宿舍 | 官方 | **优先抢!** 便宜且省心,但名额少、要摇号 |

> 🧪 **alpha 建议**:离校近的「唐楼」(无电梯旧楼)和「洋楼」(有电梯)差价明显,量力而行。

---

## 3. 黑话速查(港漂租房词典)

| 黑话 | 含义 |
|---|---|
| 免佣盘 | 业主直租,不需要付中介佣金 |
| 佣金 | 一般**半个月租金**,或租客业主各半;签约前问清谁付 |
| 按金 | 押金,一般 **2 个月租金** |
| 一年死约 | 合约期内不能退租,退了按金没了 |
| 一年生约 | 到期前通知即可续/退 |
| 打厘印 | 交印花税,租约**打了厘印才有法律效力** |
| 验楼 | 交收时核对水電錶度數、傢俬損耗,拍照存证 |

---

## 4. Flow(调用流程)

```text
网上筛选 / 约睇楼
   │
   ▼
睇楼(白天睇一次,晚上再睇一次 —— 噪声和采光会说话)
   │
   ▼
议价 + 落订(临时租约 + 定金,一般 1 个月租金)
   │
   ▼
签正式租约(看清死约/生约、维修责任、宠物/转租条款)
   │
   ▼
打厘印 + 交按金(2 个月)+ 首月租金
   │
   ▼
验楼交收(水電錶度數拍照、清單簽字)
```

---

## 5. Response(成功交付)

| 字段 | 值 |
|---|---|
| `key` | 到手(记得换锁芯或确认门锁) |
| `lease` | 已打厘印的正本一份,自己留好 |
| `stamp_duty` | 一般由业主/双方分摊,问清楚 |
| `utilities` | 水/電/煤氣/網絡开户交接(见 Troubleshooting) |

---

## 6. Status Codes(状态码,字面意思)

| Code | 含义 | 真·解决方式 |
|---|---|---|
| `200` | 簽約成功 🎉 | 恭喜,香港寸土寸金,有瓦遮頭 |
| `404` | 睇唔到樓 | 预算/区域放宽一点,或者考虑合租 |
| `409` | 撞租 | 好盘多人抢,「落订」要快,犹豫就没了 |
| `410` | 盘已过期 | 平台上的盘很多是「釣魚盤」,联系前先核对发布日期 |
| `429` | 好盘被秒抢 | 开学季(7–8 月)是高峰,提前 1–2 个月开始看 |
| `451` | 疑似凶宅/有問題 | 查「土地查冊」和凶宅網,簽約前必查 |

---

## 7. Troubleshooting(常见坑)

- 🕳️ **坑 1:网上先交钱 = 诈骗高发区。** 没睇楼、没签合同,一分钱不要转。
- 🕳️ **坑 2:没打厘印的租约 = 法律上不受保护。** 出纠纷时你哭都来不及,厘印费别省。
- 🕳️ **坑 3:学生没收入证明,可能被要求一次付清一年租。** 这是常态,和家里提前沟通资金安排。
- 🕳️ **坑 4:劏房/板间房。** 便宜,但防火、通风、隔音、电费(部分按商业电价)都是坑,预算允许别碰。
- 🕳️ **坑 5:水电煤網开户。** 有些房东包,有些不包;转名要自己跑中電/港燈/煤氣公司,入住当天没电很崩溃。
- 🕳️ **坑 6:「話俾你聽一定平過市價」的盤,多半有問題。** 天上不會掉樓。
