# `GET /api/heart` — 心情接口(人間觀察)

> 狀態:🧪 alpha — 沒有教程,只有狀態碼。
> 每個港漂嘅心裡,都住住一串咁樣嘅代碼。
> 呢個接口唔保證準確,但保證真實。

---

## 1. 真實返回嘅狀態碼樣本

| Code | HTTP 官方含義 | 港漂真實含義 |
|---|---|---|
| `200` | OK | 一切安好,今日都係好嘅一日 |
| `201` | Created | 交到咗第一個本地朋友 🎉 |
| `202` | Accepted | 今日份嘅努力,已入隊列,慢慢嚟 |
| `301` | Moved Permanently | 永久搬咗嚟香港(「回唔返去」嘅另一種講法) |
| `401` | Unauthorized | 身份證未到手,樣樣嘢都辦唔到 |
| `404` | Not Found | 搵唔到路 / 搵唔到好食嘅 / 暫時搵唔到自己 |
| `408` | Request Timeout | 等 offer、等簽證、等審核——等到麻木 |
| `413` | Payload Too Large | 行李超重,但唔捨得掉任何一件家嘅味道 |
| `418` | I'm a teapot | 手裡有杯絲襪奶茶,一切 OK ☕ |
| `429` | Too Many Requests | 想家想到過載,但係,仲係撐住咗 |
| `451` | Unavailable For Legal Reasons | 有啲嘢講唔出口,明嘅人自然明 |
| `502` | Bad Gateway | 屋企個信號,時好時壞;屋企人個電話,聽唔出我喊 |
| `503` | Service Unavailable | 今日唔想努力,聽日再努力——真係聽日,唔係明天覆明天 |
| `504` | Gateway Timeout | 畀屋企嘅視頻通話,永遠斷喺「你食咗飯未?」 |

---

## 2. 調試建議(Debugging)

- 想家嘅時候,去維港吹下風,或者落茶餐廳飲杯凍檸茶。狀態碼會自己變返 `200`。
- 撐唔住嘅時候,記住:**每一個港漂都係由 `404` 開始嘅**——唔識路、唔識話、唔識規矩,但慢慢、慢慢,都會變成 `200`。
- 交到朋友、搵到好食、考試過咗——記得記錄低你嘅 `201` 時刻,呢啲先係人生嘅 `changelog`。

---

## 3. 點解要有呢個接口

因為攻略可以寫得冷,但日子要過得暖。

呢份文檔可以幫你慳錢、慳時間、慳眼淚,但真正陪你行過夜晚嘅,係你自己嘅心態。呢個接口,係送畀未來每一個深夜睇文檔嘅你——**你唔係一個人,好多人同你一齊 404 過。**
