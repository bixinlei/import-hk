# `GET /api/job` — 港漂程序员就业(IANG 实战)

> 这是「毕业保底」接口,也是全站唯一一个面向 **CS 学生** 的专属章节。
> 毕业前 6 个月开始调用,效果最佳。

---

## 1. 为什么 CS 学生留港有优势

- **IANG 签证**:毕业即可留港工作,不需要雇主担保、不用抽签——政策上最顺的一条路。
- **香港科技生态**:金融科技 + 跨国大厂亚太总部 + 政策扶持创科,岗位真实存在。
- **薪资水平**:应届 IT 岗位月薪普遍 **HKD 20k–35k**(视公司和岗位),金融科技/量化更高。
- **双语优势**:普通话 + 英语 + 粤语(会加分) = 湾区+国际双重市场的通行证。

## 2. 香港科技公司地图(按类型)

| 类型 | 代表 | 特点 |
|---|---|---|
| 跨国大厂 | Google、Microsoft、Amazon、Meta | 流程规范,英语面试,薪资顶尖 |

## 3. 求职渠道(数据源)

| 渠道 | 说明 |
|---|---|
| LinkedIn | 主力,香港求职标配,保持英文简历 |
| JobsDB / CTgoodjobs | 本地主流招聘平台 |

| 内推 | 学长学姐、港漂群,人脉是真资源 |

> 🧪 **alpha 建议**:投递期 9–11 月(秋招)和 2–4 月(春招);应届生 IANG 窗口 6 个月,节奏可以比内地从容一点,但别拖。

---

## 4. 面试速览(常见考点)

- **算法**:LeetCode 中高难度为主,量化公司偏难。
- **系统设计**:香港岗也爱考,多准备。
- **英语**:面试大概率英语,练好技术表达。
- **粤语**:不是必须,但本地公司面试「識聽粵語」是加分项——所以现在就可以开始学(顺便用上粤语梗)。

---

## 5. IANG 与换工作

- IANG 有效期内**自由换工作**,不需要雇主批准(区别于部分其他签证)。
- 续签(3+3)时须证明「受雇且收入合理」;自雇/创业须证明业务真实运营。
- 断档期:注意 IANG 过期前续签,别让身份出现 gap。

---

## 6. Status Codes(状态码,字面意思)

| Code | 含义 | 真·解决方式 |
|---|---|---|
| `200` | Offer 🎉 | 看合同:试用期、Bonus、股票条款 |
| `401` | 简历被刷 | 英文简历 + 项目量化结果,重投 |
| `404` | 冇啱嘅崗位 | 扩类型(金融科技/初创),或先去 IANG 空窗期实习 |
| `408` | 面试流程慢 | 香港流程普遍慢,一周无回复可礼貌跟进 |
| `429` | 投太多没反馈 | 控制质量,10 份精投 > 100 份海投 |
| `451` | 薪资低于预期 | 用 offer 比价,合理谈判,别贱卖 |

## 7. Troubleshooting(常见坑)

- 🕳️ **坑 1:IANG 6 个月窗口错过。** 毕业日算起,想 gap 先申请到手再说(先拿身份,不一定要立刻上班)。
- 🕳️ **坑 2:只盯着大厂。** 香港本地中型公司和初创反而好进、成长快、还能攒粤语。
- 🕳️ **坑 3:简历还是中文。** 香港科技岗默认英文简历,改起来。
- 🕳️ **坑 4:以为不用学粤语。** 技术岗英语够用,但生活(和本地同事吃饭)会粤语体验完全不同。
