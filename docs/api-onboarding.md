# `POST /api/onboarding` — 抵港 Day-1 清单

> 落地香港的第一天,你的身份从「游客」切换成「居民」。
> 别慌,按顺序调用接口,一天搞定最关键的事。

---

## 1. 出发前(出发前 1 周,本地调用)

- [ ] 内地卡开好**国际漫游**(下飞机第一刻就要收验证码)
- [ ] 通行证 + Visa Label + D 签 三样齐(对照 `GET /api/visa`)
- [ ] 打印 Offer、住宿地址、学校紧急联系电话
- [ ] 少量港币现金(500–2000,面额 100/500)
- [ ] 转换插头(英标三脚)❗容易忘,到港再买贵且急
- [ ] 常用药、眼镜备用、证件照电子版(办证要)

---

## 2. 抵港当天(Day-0,顺序执行)

```text
过海关(学生签注通道,激活逗留身份)
   │
   ▼
买八达通(机场快线/地铁都能用)→ 前往住处
   │
   ▼
入住(宿舍/租房,登记门禁/水电)
   │
   ▼
买储值卡(机场/便利店,实名登记)→ 有本地号了
```

## 3. Day-1 到 Day-7(核心任务)

| 优先级 | 任务 | 接口 |
|---|---|---|
| 🔴 P0 | **预约办理香港身份证**(抵港 30 天内必须登记) | 入境处预约 |
| 🔴 P0 | 学校注册 / 领学生证 | 学校 |
| 🟠 P1 | 开银行账户(先虚拟银行,再实体) | `POST /api/bank` |
| 🟠 P1 | 学生八达通申请(港铁半价) | `GET /api/payment` |
| 🟠 P1 | 电话卡上台对比(学生优惠) | `POST /api/sim` |
| 🟡 P2 | 交学费 / 申请宿舍退押金 / 熟悉地铁线路 | — |
| 🟡 P2 | 医保/学校保险确认、买日用品 | — |

> 💡 **香港身份证是万能钥匙**:办银行、上台、租约、考试都要。抵港第一周就预约,热门办事处排队很久。

## 4. 交通速览(移动端导航)

| 方式 | 特点 | 支付 |
|---|---|---|
| 港铁 MTR | 骨干网络,快 | 八达通(学生半价)/ 扫码 |
| 巴士 | 覆盖广,有夜班 | 八达通 / 现金 |
| 小巴 | 快但「唔到站唔停」,要喊「有落」 | 八达通(部分现金) |
| 的士 | 贵,过海隧道加钱 | 现金 / 电子支付 |
| 天星小轮 | 便宜+看景,游客必坐 | 八达通 |

> 🧪 **alpha 提示**:学会看「站牌路線」和 Google Maps/Apple Maps 实时到站,比内地导航稍复杂,一周就熟了。

## 5. Status Codes(状态码,字面意思)

| Code | 含义 | 真·解决方式 |
|---|---|---|
| `200` | 落地成功 🛬 | 恭喜!香港歡迎你 |
| `401` | 过关被拦 | 通行证/签注带齐;D 签有效期检查 |
| `404` | 找不到住处 | 先酒店/民宿过渡,别流落街头 |
| `408` | 身份证预约抢不到 | 每天放号,早上 9 点蹲;或去偏远办事处 |
| `429` | 开学季所有窗口爆满 | 提前预约,别临时抱佛脚 |

---

## 6. Troubleshooting(常见坑)

- 🕳️ **坑 1:忘带转换插头。** 香港用英标三脚插,内地两脚插头直接废。
- 🕳️ **坑 2:身份证 30 天期限。** 逾期登记可能被罚,到港就约。
- 🕳️ **坑 3:以为内地卡能撑全场。** 本地号是刚需,第一天就办。
- 🕳️ **坑 4:行李带太多。** 香港什么都能买,带「头三天必需品」即可,被子电器到港买。
