# `GET /api/visa` — 学生签注 + IANG 规划

> 全项目最重要的一个接口。没有它,后面全是空谈。

---

## 1. 简介

内地学生赴港读书,需要两样东西的配合:

1. **学生签注(進入許可 / Visa Label)** —— 由香港入境处签发
2. **逗留(D)签注** —— 贴在内地通行证上,由内地公安机关签发

「兩樣嘢,缺一不可。」 💡

---

## 2. Request(请求参数)

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `offer` | `string` | ✅ | 学校录取通知书(Conditional 的可以,换 Fulfil 后补) |
| `form` | `ID995A` | ✅ | 入境处申请表格,一般由学校系统发放 |
| `funds` | `proof` | ✅ | 经济证明(存款证明,覆盖学费+生活费) |
| `passport` | `image` | ✅ | 通行证信息页扫描件 |
| `photo` | `image` | ✅ | 证件照(白底) |
| `sponsor` | `string` | 条件 | 未成年或由他人资助时 |

---

## 3. Flow(调用流程)

```text
拿到 Offer
   │
   ▼
学校系统填 ID995A + 上传材料 ──► 学校代为递交入境处
   │                                  │
   ▼                                  ▼
等待审理(一般 4–8 周)          ⚠️ 高峰期更久,尽早提交
   │
   ▼
收到 Visa Label(進入許可标签,电子版/纸本)
   │
   ▼
凭 Visa Label 去内地公安出入境 办「逗留(D)签注」
   │
   ▼
抵港过关时激活 ──► 你的逗留期限正式开始
```

---

## 4. Response(返回结果)

| 字段 | 说明 |
|---|---|
| `duration` | 学生签注一般按学制批,如 1 年硕士批 12 个月 |
| `work_permit` | ⚠️ 学生身份兼职有限制,以入境处最新政策为准 |
| `dependents` | 配偶/子女可申请受养人签注(如适用) |

---

## 5. Status Codes(状态码,字面意思)

| Code | 含义 | 真·解决方式 |
|---|---|---|
| `200` | 获批 🎉 | 立刻办 D 签,别拖 |
| `401` | 材料不齐 | 对照表格逐项检查,缺一不可 |
| `403` | 经济证明不足 | 存款证明金额要覆盖「学费 + 生活费」 |
| `408` | 审理超时 | 正常 4–8 周,催学校入境处协调,别自己乱发邮件轰炸 |
| `429` | 办理名额被抢 | 内地出入境 D 签可预约,早上蹲点约号 |
| `500` | 学校系统崩了 | 等,顺便骂一下教务处(开玩笑的) |

## 6. 毕业后的关键接口:`IANG`

> **IANG**(Immigration Arrangements for Non-local Graduates)是港漂程序员的「毕业保底」。

| 场景 | 规则 |
|---|---|
| 应届申请 | 毕业 **6 个月内** 申请,**无需先有工作** |
| 非应届申请 | 毕业超 6 个月,须**先获聘用**再申请(「回港就业」) |
| 首次有效期 | 一般 **24 个月** |
| 续签 | 通常 `3 + 3` 年,须受雇(自雇/创业亦可,须证明业务) |
| 长期目标 | 通常连续通常居住满 **7 年** 可申香港永久居民(「通常居住」含读书时间) |

**给程序员的解读**:IANG 就是你的「应届毕业生专属工作签证」,24 个月有效期,不需要雇主担保就能找工作——比优才/高才通灵活得多,是留港的最大底气。

---

## 7. Troubleshooting(常见坑)

- 🕳️ **坑 1:Visa Label 有效期不等人。** 收到后注意入境期限,过期要重新申请。
- 🕳️ **坑 2:D 签和 Visa Label 都要。** 只有 Visa Label 没有 D 签,出不了内地海关。
- 🕳️ **坑 3:办理顺序不能反。** 先 Visa Label,后 D 签。
- 🕳️ **坑 4:IANG 的 6 个月窗口从毕业日算起。** 想 gap 的话提前规划,别错过「免工作申请」窗口。
- 🕳️ **坑 5:学生期间想打工?** 政策近年有放宽(如研究生兼职),但限制仍在——开工前查入境处官网,别因小失大。

---

## 8. 来源与验证

- 官方:香港入境事务处官网(`immd.gov.hk`,搜索「IANG」「學生簽證」)
- 官方:内地公安出入境管理局(办 D 签)
- ⚠️ 政策会变,本页所有「时长/金额」以你申请时的官方发布为准。
