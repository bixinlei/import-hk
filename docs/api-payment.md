# `GET /api/payment` — 支付生态(八达通 / FPS / 扫码)

> 到港第一天你会发现:手机支付没有内地那么「一统江湖」。
> 香港是「八达通 + 转数快 + 扫码 + 现金 + 信用卡」的**多支付协议并存**生态。

---

## 1. 支付方式总览(protocol overview)

| 方式 | 覆盖率 | 场景 | 内地同学上手难度 |
|---|---|---|---|
| **八达通** | ⭐⭐⭐⭐⭐ | 交通、便利店、快餐、街市 | 低(就是香港版「一卡通」) |
| **FPS 转数快** | ⭐⭐⭐⭐ | 即时转账、收付款 | 中(绑手机号/邮箱,需本地银行) |
| **AlipayHK / WeChat Pay HK** | ⭐⭐⭐⭐ | 商场、餐厅、网店 | 低(内地 App 在香港很多商户也能直接用) |
| 信用卡 / 借记卡 | ⭐⭐⭐ | 大额、网上、积分 | 中(需本地卡或国际卡) |
| 现金 | ⭐⭐ | 街市、小店、应急 | 低(别带太多) |

---

## 2. 八达通(核心协议)

- **用途**:港铁、巴士、便利店(7-11/OK)、快餐、街市、停车场……几乎万物。
- **学生八达通**:港铁 **半价**!学生身份申请,港铁官网/App 办理,能省一大笔通勤费。
- **办理**:地铁站客服中心买普通卡(押金+储值);学生卡需在学校注册后申请。
- **App**:八达通 App 可绑定手机 NFC 拍卡,也能查看余额与交易记录。
- **提示**:余额不足会「嘟」一声就进不了闸,养成充值习惯;便利店、地铁站都能充,部分支持自动增值。

> 🧪 **alpha 建议**:有八达通 + 手机扫码,基本覆盖 95% 的日常支付,现金留几百块应急即可。

---

## 3. FPS 转数快(支付界的「即时消息」)

- 香港本地**即时转账系统**,24/7 秒到,免手续费。
- 绑定方式:手机号 或 邮箱 或 FPS ID。
- 场景:AA 分账、交房租、和本地同学拆账——「转数快,唔使現金」。
- ⚠️ 前提:需要一张香港本地银行卡(见 `POST /api/bank`)。

---

## 4. 内地支付工具在香港

- **支付宝 / 微信支付(内地版)**:香港大量商户支持,按实时汇率自动结算人民币,汇率通常不错。
- **AlipayHK / WeChat Pay HK(港版)**:支持更多本地场景(如港铁扫码、政府缴费),可用内地充值或绑定香港卡。
- 结论:**内地版 App 先撑住第一天,港版 App + 本地银行卡逐步补齐。**

---

## 5. 现金与信用卡

- 现金:港币。**1000 元大钞部分小店不收**(怕假钞),多备 100/500 面额。
- 信用卡:本地卡(见银行篇)或内地 Visa/Mastercard(有货币转换费,留意汇率)。
- 学费、大额支出:优先走银行转账/电汇,别扛现金。

---

## 6. Status Codes(状态码,字面意思)

| Code | 含义 | 真·解决方式 |
|---|---|---|
| `200` | 支付成功 | 記得看小票,香港很多店要「對單」(核对金额) |
| `402` | Payment Required 但余额不足 | 充八达通 / 转钱进银行卡 |
| `404` | 該店唔收呢種支付方式 | 换一种协议,这就是多支付生态的日常 |
| `409` | 重复扣款 | 先查账单再补付,别急着二次支付 |
| `429` | 八达通拍太快/闸机报错 | 等几秒重拍,或去客务中心 |
| `451` | 汇率不划算 | 大额消费前对比支付宝/银行卡汇率 |

---

## 7. Troubleshooting(常见坑)

- 🕳️ **坑 1:学生八达通没申请 = 多付一倍车费。** 到港第一周就办,别拖。
- 🕳️ **坑 2:内地手机号收不到香港短信验证码?** 办本地卡前,把内地卡开国际漫游(见 `POST /api/sim`)。
- 🕳️ **坑 3:小额现金还是要有。** 街市阿姨、小巴(部分只收现金/八达通)会教你做人。
- 🕳️ **坑 4:不要一次性带几万现金过关。** 跨境带大额现金有申报规定,走银行通道。
