# `GET /api/culture` — 香港文化礼仪

> 排队、电梯、台风、利是——港漂文化生存手册。

---

## 1. 社交礼仪速记

| 场景 | 规矩 |
|---|---|
| 排队 | 极重排队,「打尖」(插队)是大忌 |
| 扶手电梯 | 站稳靠右,左边留给赶路的人 |
| 「唔該」 | 让路、借过、麻烦别人,一句唔該解决 80% 社交 |
| 小费 | 无强制小费,餐厅一般已含 10% 服务费 |
| 公共空间 | 整体安静,打电话压低声音 |
| 茶楼 | 别人倒茶时食指中指轻叩桌面表谢意(叩指礼) |

## 2. 港式习俗

- **利是(红包)**:过年/开工派利是,金额随意(20-100),重在心意
- **打台风**:八号风球/黑雨=停工停课,留意天文台信号,提前囤粮
- **茶餐厅效率**:落单要快,「凍飲加三蚊」,食完即走是尊重
- **叮叮(电车)**:后门上车前门落,便宜且浪漫

## 3. 禁忌与敏感

- 送礼物避免「鐘」(送钟=送终),「書」谐音输
- 尊重本地人,不用歧视性称呼
- 社会议题敏感,初来乍到保持倾听,别急着站队
- 部分楼宇避开 4 字层(四=死),电梯用 3A 代替,知道不尴尬

## 4. 融入三步曲

识排队 → 识唔該 → 识饮茶,顺序别乱。
多和本地同学吃饭,一顿茶餐厅学到的比一本书多。
