# `GET /api/health` — 医疗与保险

> 港漂看病指南:公立 vs 私家、学校保险、急诊流程、牙科。

---

## 1. 保险三件套

| 类型 | 说明 |
|---|---|
| 学校保险 | 多数港校强制/自动包含基础医疗险,报到时确认覆盖范围 |
| 个人医疗险 | 想住私家医院/私立诊所,建议补充 |
| 内地医保 | 在港不直接报销,保留票据部分可走内地流程(以政策为准) |

## 2. 看病选择

| 选项 | 费用 | 等待 | 适用 |
|---|---|---|---|
| 公立医院/门诊 | 便宜(专科需转介) | 排期长(可等数月) | 慢性病、普通科 |
| 私家诊所(普通科) | 中等(300-600/次) | 快,当天可看 | 感冒发烧常见病 |
| 私家医院 | 贵 | 快,服务好 | 有保险/急症不想排队 |
| 牙科 | 贵(洗牙几百起) | 公立以年计 | 建议出发前在内地看完牙 |

## 3. 急诊

- **999** 紧急求助
- 急症直接去公立医院急症室,按分流等级(危殆/紧急/次紧急/非紧急)
- **非急症千万别去急症室排**,几小时起,看私家诊所更快

## 4. 常见坑

- 香港专科要转介信(Referral),不是随便挂专家号
- 牙科超贵且公立排期以年计,出发前把牙看完
- 处方药必须看医生;非处方药去「药房」买
- 保留所有医疗票据,保险理赔和内地报销都要用
