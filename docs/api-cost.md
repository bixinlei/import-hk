# `GET /api/cost` — 生活成本预算

> 港漂月预算速查:房租/饮食/交通/杂项 + 学生省钱地图。

---

## 1. 月预算速查

| 项目 | 范围(HKD) | 备注 |
|---|---|---|
| 房租 | 6,000-12,000 | 合租单间或近校区,占大头 |
| 饮食 | 3,000-5,000 | 食堂为主+偶尔茶餐厅,外卖贵 |
| 交通 | 500-800 | 学生八达通半价后大幅降低 |
| 通信 | 100-200 | 学生上台套餐 |
| 杂项 | 2,000-4,000 | 日用品/娱乐/聚餐,弹性最大 |

**月总预算参考:HKD 12,000-20,000**(丰俭由人)

## 2. 省钱地图

- 学生八达通港铁半价,最大固定优惠,第一周就办
- 学校食堂比外面便宜 30-50%,两餸飯是穷鬼套餐天花板
- 超市比便利店便宜;街市买菜自己煮最省
- 学生优惠到处有:电影票、App 订阅、博物馆,出示学生证问一句
- 外卖平台新用户券/补贴期囤券再点(Keeta 进港时补贴最猛)
- 学费一次付清注意汇率窗口,大额换汇对比各银行

## 3. 隐藏支出(一次性)

- 租房押金(2 个月)+ 首月租金
- 首次置办:转换插头、被子、厨具
- 学费按学期交,预留 5-10 万人民币级别(看学校和专业)
- IANG/续签、证件照、复印等杂费
