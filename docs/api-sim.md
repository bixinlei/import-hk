# `POST /api/sim` — 电话卡「上台」与网络

> 没有本地号码,你在香港几乎寸步难行:
> 银行开户要收验证码、FPS 要绑手机号、外卖要填电话……
> 「一張卡,搞掂所有嘢。」

---

## 1. 前置知识(protocol 基础)

- **实名登记**:2022 年 3 月起,香港所有电话卡(含储值卡)**必须实名登记**才能用。
- **上台**:签月费合约(如 12/24 个月),一般要提供证件+住址。
- **储值卡**:预付卡,即买即用,灵活但单位流量贵一些。

---

## 2. 运营商对比

| 运营商 | 特点 | 适合谁 |
|---|---|---|
| **CMHK(中国移动香港)** | 内地+香港数据共享套餐多,内地通话优惠 | 频繁往返内地的同学(主流选择) |
| **3HK(和記)** | 本地数据套餐灵活,学生优惠多 | 本地用量大的同学 |
| **香港電訊 HKT / csl** | 信号覆盖最好,价格偏高 | 追求稳定、不差钱 |
| **数码通 SmarTone** | 覆盖好,价位居中 | 综合性价比 |
| **中国联通香港** | 同样有内地联动套餐 | 内地联动需求 |

> 🧪 **alpha 建议**:先买一张储值卡撑过第一周,确认常待区域(宿舍/校区)信号后,再决定上台哪家——别在机场柜台冲动签约。

---

## 3. Request(上台所需材料)

| 材料 | 说明 |
|---|---|
| 通行证 / 护照 | 实名登记必需 |
| 学生签注 | 部分学生套餐要求 |
| **学生证**(注册后) | 学生优惠凭证 |
| 住址 | 上台要留地址(收账单) |

---

## 4. Flow(调用流程)

```text
到港第一件事:买一张储值卡(机场/便利店/运营商门店)
   │
   ▼
实名登记(门店/App,扫证件即可)
   │
   ▼
学校注册拿到学生证
   │
   ▼
对比学生上台套餐(开学季优惠多)
   │
   ▼
签约上台 → 获得本地号码 + 流量套餐
```

---

## 5. 内地卡怎么办(双卡策略)

- 内地手机号**保留**:收内地银行验证码、App 短信,但**国际漫游很贵**——到港前改一个便宜的低月租套餐,或开漫游包。
- 双卡手机:内地卡(漫游/保号)+ 香港卡(主用流量和本地通话),是绝大多数港漂的标配。
- ⚠️ 用内地卡在香港频繁收验证码没问题,但**不要用内地卡开流量漫游日常上网**,流量费会让你肉疼。

---

## 6. Status Codes(状态码,字面意思)

| Code | 含义 | 真·解决方式 |
|---|---|---|
| `200` | 開通成功 📶 | 马上绑 FPS、银行、外卖 App |
| `401` | 实名登记不通过 | 证件照片拍清楚,不行就门店人工处理 |
| `403` | 上台被拒 | 多数是学生证未到手,先用储值卡过渡 |
| `404` | 冇信號 | 地下室/地铁隧道正常,别慌 |
| `408` | 漫游认证慢 | 重启手机/开关飞行模式 |
| `429` | 套餐抢光了 | 开学季热门学生套餐限量,留意活动上线时间 |

---

## 7. Troubleshooting(常见坑)

- 🕳️ **坑 1:在机场柜台被推销「超值套餐」。** 先买储值卡过渡,冷静对比后再上台。
- 🕳️ **坑 2:学生套餐要学生证。** 注册前先问清楚,别办了个贵价套餐。
- 🕳️ **坑 3:签约上台 = 合约绑定。** 违约金了解一下再签字,短期交换生别签长约。
- 🕳️ **坑 4:内地卡保号费。** 每月几块钱,但忘缴费被销号,内地银行 App 全废,设置自动缴费。
