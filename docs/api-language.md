> 从「識聽」到「識講」:高频用语、学习资源、港漂粤语生存术。

## 1. 高频用语(第一周够用)

| 用语 | 拼音 | 用法 |
|---|---|---|
| 唔該 | m4 goi1 | 万能词:谢谢、劳驾、麻烦你 |
| 多謝 | do1 ze6 | 收到礼物/别人主动帮忙时说 |
| 早晨 | zou2 san4 | 早上好,茶餐厅必用 |
| 唔使驚 | m4 sai2 geng1 | 不用怕,港漂心理建设第一句 |
| 埋單 | maai4 daan1 | 结账 |
| 有落 | jau5 lok6 | 小巴下车喊「有落」 |
| 得閒飲茶 | dak1 haan4 jam2 caa4 | 有空喝茶(礼貌告别) |
| 平啲啦 | peng4 di1 laa1 | 便宜点吧(街市讲价) |
| 唔該借借 | m4 goi1 ze3 ze3 | 借过一下 |
| 你食咗飯未 | nei5 sik6 zo2 faan6 mei6 | 经典问候 |

## 2. 学习路径

1. 先学「識聽」,再「識講」——听力是口语基础
2. 高频词优先级:唔該 > 多謝 > 早晨 > 埋單,撑过第一周
3. 先背数字 1-10(菜价、车牌、楼层都要用)
4. 香港人普通话普及度高,不会粤语能活,会粤语活得更亲

## 3. 资源

- TVB / 港剧:带中文字幕练听力,免费地道
- 香港电台 RTHK:新闻播报,标准粤语
- 「粤语协会」公众号:拼音标注教学
- 语言交换 App(HelloTalk 等):找本地人练口语
- B站/YouTube「學講廣東話」系列:免费教程
