## 2. 学生食堂攻略(性价比之王)

- 港校食堂普遍比外面便宜 30–50%,两餸/三餸飯(选菜配饭)是经典。
- 开放时间注意:周末和节假日很多食堂不开,提前备粮。
- 用学生证可能有优惠,问一句「有冇學生價?」不吃亏。

## 4. 飲嘢(饮品文化,社会学必修)

- **奶茶/手摇**:本地品牌多,「少甜少冰」是标准话术。
- **港式奶茶/鸳鸯**:茶餐厅灵魂,「絲襪奶茶」,下午茶套餐配蛋挞或菠萝油。
- **「凍飲加三蚊」**:点热饮便宜,冻饮加钱——粤语区生活经济学第一课。

## 5. Status Codes(状态码,字面意思)

| Code | 含义 | 真·解决方式 |
|---|---|---|
| `200` | 好味 😋 | 记下店名,回头带同学 |
| `402` | 唔够錢 | 学生餐/食堂是避风港 |
| `404` | 搵唔到間鋪 | 香港小店搬得快,看 Google 评价 + 实地找 |
| `409` | 食堂撞上饭点 | 12:00–13:00 人多,错峰去 |
| `418` | I'm a teapot | 正確,你手上正係一杯絲襪奶茶 ☕ |
| `429` | 排隊太長 | 网红店晚上 8 点后去,或打包走 |

## 6. Troubleshooting(常见坑)

- 🕳️ **坑 1:以为「辣」= 内地辣。** 香港辣度普遍温和,「大辣」≈ 内地中辣,点单前想清楚。
- 🕳️ **坑 2:周末食堂关门。** 提前囤,或解锁茶餐厅。
- 🕳️ **坑 3:茶餐厅效率文化。** 「唔該,落單!」——你犹豫太久,伙记会礼貌地站在你旁边(物理)。
- 🕳️ **坑 4:觉得贵。** 第一周正常,找到学校食堂和街市后,月生活费能压到合理水平。
