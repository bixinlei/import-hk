# `POST /api/bank` — 银行开户与跨境汇款

> 在香港,「銀行開戶」是留学生的第一场「身份认证」:
> 有了本地账户,才能收工资、交房租、用 FPS、办信用卡。

---

## 1. 主流银行对比

| 银行 | 类型 | 内地同学友好度 | 备注 |
|---|---|---|---|
| **中银香港 (BOCHK)** | 传统银行 | ⭐⭐⭐⭐⭐ | 与内地中国银行联动,跨境汇款便利 |
| **汇丰 (HSBC)** | 传统银行 | ⭐⭐⭐⭐ | 网点多,国际业务强 |
| **渣打 (Standard Chartered)** | 传统银行 | ⭐⭐⭐⭐ | 对学生开户积极 |
| **恒生 (Hang Seng)** | 传统银行 | ⭐⭐⭐⭐ | 网点多,与内地恒生/工行有关联 |
| **ZA Bank / livi / Mox** | 虚拟银行 | ⭐⭐⭐⭐ | 线上开户,零门槛起步神器 |

> 🧪 **alpha 建议**:抵港后先开一个虚拟银行(当天搞定),再去中银香港开实体账户——两头都不耽误。

---

## 2. Request(开户材料)

| 材料 | 说明 |
|---|---|
| 通行证 / 护照 | 身份证明原件 |
| 学生签注(进入許可) | 证明合法逗留 |
| **住址证明** | 3 个月内的账单/学校宿舍证明/租房合同——**最常见的卡点** |
| 录取通知书 / 学生证 | 部分银行要求学生身份 |
| 内地身份证 | 部分银行要求辅助证明(开户时问清楚) |

> ⚠️ **住址证明是最大变量**:租房没账单的话,先用学校开的住宿证明/宿舍信,或者用内地地址的银行账单(部分银行接受)。开户前打电话问该分行接不接受。

---

## 3. Flow(调用流程)

```text
预约(网上/App 或分行排队,热门分行建议预约)
   │
   ▼
到分行/线上提交材料
   │
   ▼
银行审核(当场或 1–2 个工作天)
   │
   ▼
拿到账户 + 提款卡
   │
   ▼
(可选)开通手机银行 + 绑定 FPS 转数快 + 申请信用卡
```

---

## 4. 跨境汇款(内地 ⇄ 香港)

| 方式 | 速度 | 费用 | 适用 |
|---|---|---|---|
| 内地银行电汇到香港账户 | 1–3 天 | 手续费+中转行费 | 大额(学费、生活费) |
| **中银「两地账户」联动** | 快 | 低/免 | 中银内地↔中银香港 |
| 汇丰 Global Money / 跨境转账 | 快 | 看账户等级 | 汇丰体系 |
| 支付宝/微信(限额外币) | 即时 | 汇率+手续费 | 小额应急 |

> 💡 **学费建议**:提前把大额资金走正规银行渠道,留好汇款凭证(入境处/学校偶尔要资金来源证明)。

---

## 5. Status Codes(状态码,字面意思)

| Code | 含义 | 真·解决方式 |
|---|---|---|
| `200` | 开户成功 🎉 | 立刻设手机银行、绑 FPS |
| `401` | 材料不全 | 九成是住址证明,补齐再来 |
| `403` | 审核不通过 | 换一家银行/虚拟银行,别死磕 |
| `408` | 排队 3 小时 | 提前预约,学生季(8–9 月)分行爆满 |
| `429` | 开户名额限制 | 有的银行对学生有名额,早办早省心 |
| `500` | 系统维护 | 香港银行也维护,改天再来 |

---

## 6. Troubleshooting(常见坑)

- 🕳️ **坑 1:没有住址证明被拒。** 抵港前联系学校要「住宿證明信」,或租房时让业主出合同。
- 🕳️ **坑 2:通行证和签注没带齐。** 原件+复印件都带,开户当场要核对。
- 🕳️ **坑 3:虚拟银行开户地址填内地也能过?** 各家要求不同,以 App 内要求为准,别造假。
- 🕳️ **坑 4:信用卡「學生卡」额度低但积累信用。** 毕业后办贷款/信用卡会看本地信用记录,从学生卡开始养。
- 🕳️ **坑 5:汇款被冻结/需要资金来源证明。** 大额一次性入账可能触发合规审查,保留学费收据和汇款凭证。
